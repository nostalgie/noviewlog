# noviewlog-tui

NoViewLog terminal UI host — runs the NoViewLog engine as a TUI inside any
ANSI terminal emulator (local shell or SSH sessions via the system `ssh` in
a PTY).

Features: transparent-terminal UX (no key modes, self-contained mouse
selection), filter tabs with include/exclude rules, diff-based repaint with
a frame budget, CJK-aware cell layout.

See the workspace root for build instructions.
